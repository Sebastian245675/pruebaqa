Ideas para practicar QA

  • Validar campos obligatorios y formato de correo.
  • Probar contrasenas diferentes en el registro.
  • Intentar acceder a /dashboard sin iniciar sesion.
  • Verificar mensajes de exito, error y cierre de sesion.
  • Automatizar formularios usando los id y data-testid.
